This simulator runs the actual DSP from the Zero EQ plugin (8-band zero-added-latency parametric EQ, per-band dynamic EQ with external sidechain, band-isolated harmonic generation, and a soft-knee compressor), compiled unmodified to WebAssembly and running in an AudioWorklet. Uploaded audio never leaves your browser. The “safety clip” output stage is web-only and not part of the plugin.

Parts of this project were built with AI assistance; the DSP core is verified against the plugin’s own test methodology. © Stoatworks. Audio sources are synthesized in-browser — no third-party media.
